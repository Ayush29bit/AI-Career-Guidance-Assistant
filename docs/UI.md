# UI

## Core Principle

Conversation first.

The primary interaction is a chat-like conversation with the AI counsellor.

The user should not need to navigate forms or click buttons to get recommendations.

## Main Layout

Recommended:

Left / main:
- Conversation

Right / supporting panel:
- Student profile
- Current career recommendations
- Skill gaps
- Roadmap when available

On smaller screens these become stacked sections.

## Conversation

The counsellor should feel warm, intelligent and professional.

Avoid:

- Long walls of text
- Generic chatbot language
- Repeated questions
- Excessive buttons
- Form-heavy onboarding

## Recommendation Cards

Show:

- Career name
- Suitability score
- Why it fits
- Key strengths
- Main concerns
- Relevant skill gaps

## Skill Gaps

Show prioritized gaps visually.

Example:

MLOps
████████░░
High Priority

Model Deployment
███████░░░
High Priority

## Courses

Course cards should show:

- Course title
- Organization
- Rating
- Difficulty
- Duration
- Relevant skill
- Coursera link when available

## Roadmap

Show a simple sequence:

Step 1 → Step 2 → Step 3 → Step 4

Each step should explain:

- Skill
- Why it matters
- Recommended course if available
- Approximate duration

## Design

Use a clean, modern blue-and-white visual system.

Keep:

- Minimal
- Spacious
- Professional
- Accessible
- Responsive

Avoid excessive animations and decorative elements.

## UX Goal

The user should leave feeling:

"This system actually understood me."
